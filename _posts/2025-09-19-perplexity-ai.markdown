# Perplexity AI

[Perplexity AI](https://www.perplexity.ai/) is an advanced AI-powered search and question-answering platform. It leverages large language models (LLMs) to provide accurate, up-to-date answers and information from the web, combining generative AI with real-time search capabilities.

## Key Features
- Natural language search and Q&A
- Uses multiple LLMs for high-quality responses
- Cites sources for transparency
- Supports web browsing and document search
- Available via web, browser extensions, and API

## Use Cases
- Research and fact-checking
- Summarizing articles and documents
- Generating answers to complex questions
- Assisting with coding, writing, and brainstorming
